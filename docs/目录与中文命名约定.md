# 屏幕观测工具目录与中文命名约定

本仓库维护 **Android 实际画面、帧统计、控件树与 logcat 的只读观测工具**，与游戏 MOD 正式业务代码分离。

| 目录或文件 | 用途 |
| --- | --- |
| `README.md`、`AGENTS.md`、`CLAUDE.md` | 中文入门说明与 Agent 标准规则 |
| `app/` | Android Kotlin/资源实现，按 Gradle 工程约定保留英文路径 |
| `build.gradle`、`settings.gradle`、`gradle.properties` | Gradle 工具链配置，文件名不能翻译 |
| `tools/` | 设备连接、验证与辅助工具 |
| `docs/` | 中文接口、权限与使用说明 |
| `savestates/` | 脱敏且有来源记录的测试存档 |
| `archive/` | 历史暂停与旧规范（`archive/项目暂停记录.md`） |

## 中文化原则

- 用户可见操作指南、故障排查、图表标题、PR 与 Issue 使用自然简体中文。
- HTTP 路由 `/ui`、`/stats`、`/timeline`，Android 包名、Gradle 配置和 ABI 名称保持原样。
- 根目录不再放 `PROJECT_PAUSED.md` 形式的历史状态快照；最新任务状态以用户授权、GitHub、实际工具和有效任务文件判断。
- 观测工具必须只读。任何“中文化”或清理不得改变用户授权、MediaProjection 系统确认、无障碍权限或目标包白名单行为。
- 不清理或覆盖设备采集的原始证据、私人存档或其他项目的工作目录；历史数据只作安全归档。
