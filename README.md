# frame-observer

Android 真实屏幕观测工具，用于截图、帧时间线、无障碍控件树、事件和 logcat 对齐。它只观测，不代替游戏逻辑，也不执行点击或按键。

## 1. 用途

### 1.1 适用场景

- 验证 Android MOD 的真实 GUI；
- 对比调度器/自动购买器操作前后的屏幕；
- 记录阶段显示、弹窗和控件 bounds；
- 将截图、控件树和日志按时间线关联。

### 1.2 不负责的事情

工具不修改 APK、不注入游戏代码、不执行自动点击、不绕过 MediaProjection 或 FLAG_SECURE，也不收集白名单包之外的应用内容。

## 2. 使用前提

1. 连接目标 Android 设备或 AVD；
2. 按系统提示人工授予屏幕捕获权限；
3. 如需控件树，人工启用无障碍服务；
4. 确认设备序列号和目标包名；
5. 记录 APK SHA-256、存档策略和测试场景。

共享 AVD 必须串行使用。不要用 `adb force-stop` 或清除数据破坏正在采集的长跑测试。

## 3. 观测入口

完整参数和响应格式见 [接口说明](docs/接口说明.md)。常用入口：

| 入口 | 用途 |
|---|---|
| `/` | 状态页与当前帧预览 |
| `/snapshot.jpg` | 最新截图 |
| `/stats` | 采集状态与帧统计 |
| `/ui` | 即时控件树，不依赖 UIAutomator idle |
| `/events` | 无障碍事件增量 |
| `/timeline` | 操作、截图和日志时间线 |
| `/logcat` | 受控日志读取与导出 |

采集服务默认只绑定本机回环地址；通过 `adb forward` 访问，不对局域网开放。

## 4. 证据要求

### 4.1 截图

关键场景至少保存操作前、操作后和稳定状态三张截图，并记录设备、时间、APK 身份和存档。

### 4.2 控件树

按钮节点存在不等于屏幕可见或可点击。使用本次观测得到的 bounds，不复用旧坐标；截图降采样时按实际比例换算。

### 4.3 安全

密码框脱敏；白名单包之外的事件不落盘；停止采集后释放 MediaProjection、VirtualDisplay 和 ImageReader。

## 5. 故障排查

| 现象 | 处理 |
|---|---|
| 截图返回 503 | 确认人工授予捕获权限且采集已开始 |
| `/ui` 返回无障碍缺失 | 重新启用服务，等待系统完成绑定后重试 |
| 帧率低 | 先区分画面静止导致的低产帧和真实丢帧 |
| 坐标不一致 | 核对截图分辨率、设备物理分辨率和缩放比例 |
| 连接超时 | 检查 `adb forward`，只移除本工具自己的转发 |

## 6. 开发

源码和构建命令以仓库实际脚本、`pyproject.toml`/构建配置和 `docs/` 为准。新增功能必须保留隐私边界、只观测不操作，并补充定向测试和接口说明。
