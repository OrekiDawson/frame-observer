# Oreki Frame Observer

Android 真实屏幕观测工具，用于采集截图、帧统计、无障碍控件树、事件和 logcat，并把证据按时间线关联。它只观测目标设备，不修改游戏逻辑、不注入 APK、不执行自动点击或按键。

## 1. 适用场景

- 验证 Android MOD 的真实 GUI；
- 对比调度器或自动购买器操作前后的屏幕状态；
- 记录阶段页签、弹窗、按钮 bounds 和可见性；
- 将截图、控件树、事件和日志绑定到同一测试时间线。

## 2. 安全边界

1. 只采集用户明确指定的设备和白名单应用。
2. 不绕过 MediaProjection、FLAG_SECURE 或系统权限。
3. 不执行自动点击、按键、存档删除、应用清除数据或 APK 修改。
4. 密码框和敏感内容必须脱敏；停止采集后释放 MediaProjection、VirtualDisplay 和 ImageReader。
5. 共享 AVD 必须串行使用；不得强制停止或清除其他任务正在使用的应用和存档。

## 3. 开始使用

需要 JDK、Android SDK、Android Build Tools、Gradle Wrapper 和 adb。连接设备或启动 AVD 后，按系统提示人工授予屏幕捕获权限；需要控件树时，人工启用无障碍服务，并记录设备序列号、目标包名、APK SHA-256 和存档策略。

```bash
./gradlew assembleDebug --offline --no-daemon --console=plain
```

默认包名为 `com.oreki.frameobserver`。签名配置和口令要求以 `app/build.gradle` 与当前规则为准，不把口令写入仓库。

## 4. 观测入口

启动采集服务后，通过 `adb forward` 访问本机回环地址。完整参数和响应格式见 [接口说明](docs/接口说明.md)。常用入口：

| 入口 | 用途 |
|---|---|
| `/` | 状态页与当前帧预览 |
| `/snapshot.jpg` | 最新截图 |
| `/stats` | 采集状态与帧统计 |
| `/ui` | 即时控件树 |
| `/events` | 无障碍事件增量 |
| `/timeline` | 操作、截图和日志时间线 |
| `/logcat` | 受控日志读取与导出 |

服务默认只绑定本机回环地址，不对局域网开放。

## 5. 证据要求

### 5.1 截图

关键场景至少保存操作前、操作后和稳定状态截图，并记录设备、时间、APK 身份、存档和测试条件。

### 5.2 控件树

控件节点存在不等于屏幕可见或可点击。操作前重新读取当前 bounds，不复用旧坐标；截图缩放时按当前分辨率换算。

### 5.3 结果状态

报告分别记录 `PASS`、`FAIL`、`BLOCKED` 和 `NOT RUN`。日志或控件树不能单独替代真实屏幕截图；截图也不能单独证明业务状态已经正确结算。

## 6. 故障排查

| 现象 | 检查 |
|---|---|
| 截图返回 503 | 确认人工授予捕获权限且采集已开始 |
| `/ui` 没有控件树 | 重新启用无障碍服务并等待绑定完成 |
| 帧率低 | 区分画面静止导致的低产帧和真实丢帧 |
| 坐标不一致 | 核对截图、物理分辨率、显示缩放和旋转 |
| 连接超时 | 检查 adb 转发，只移除本工具自己的转发 |

## 7. 开发与反馈

源码位于 `app/src/main/kotlin/`，构建和权限配置位于 Gradle 文件，接口说明位于 `docs/`。新增功能必须保持“只观测不操作”的边界，并补充定向测试和接口说明。问题报告请提供设备、Android 版本、工具版本、复现步骤和脱敏日志。
